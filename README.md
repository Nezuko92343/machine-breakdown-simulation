# Імітаційне моделювання верстата з поломками

Курсова робота (варіант B19): подійна імітаційна модель верстата, що обробляє потік завдань і періодично ламається, її верифікація та експерименти з базовою й модифікованою системою.

## Опис моделі

**Базова система.** Завдання надходять на верстат у середньому раз на годину (експоненційний розподіл) і утворюють чергу. Обробка завдання складається з наладки (рівномірний розподіл 0,35 ± 0,15 год) і виконання (нормальний розподіл із середнім 0,5 год і СКВ 0,1 год). Верстат ламається через нормально розподілений час безвідмовної роботи (20 ± 2 год). Ремонт складається з трьох фаз з експоненційною тривалістю із середнім 0,75 год, тобто має розподіл Ерланга. Перерване поломкою завдання повертається в початок черги й дообробляється з місця переривання.

**Модифікована система** додає два механізми:

- **субпідрядник** — під час поломки завдання з черги понад `keep` (3) передаються субпідряднику;
- **запасні деталі** — у середньому раз на 100 год виникає потреба в запасних деталях; якщо в цей момент триває ремонт, він призупиняється на 3 год.

Усі параметри зібрано у словнику `PARAMS` на початку ноутбука.

### Вихідні характеристики

| Позначення | Зміст |
| --- | --- |
| `U` | завантаження верстата обробкою завдань |
| `P_rep` | частка часу, коли верстат у ремонті |
| `W`, `sigma_W` | середній час перебування завдання в системі та його СКВ |
| `W_min`, `W_max` | найменший і найбільший час перебування |
| `L` | середня довжина черги |
| `lambda_out` | інтенсивність виходу виконаних завдань |
| `P_sub` | частка завдань, переданих субпідряднику |

## Структура репозиторію

```
.
├── notebooks/
│   └── coursework_B19.ipynb   # модель, верифікація та експерименти
├── requirements.txt           # залежності Python
├── .gitignore
└── README.md
```

Ноутбук поділено на розділи:

1. Імітаційна модель (класи `Generator`, `Source`, `Device`, `MachineModel`).
2. Трасування подій.
3. Швидка перевірка за 10 прогонами.
4. Верифікація: перевірка генераторів, протоколи подій, реакція на зміну параметрів.
5. Експерименти: тривалість моделювання, перехідний період, кількість прогонів, основна серія, дисперсійний аналіз, закони розподілу.
6. Пропозиції щодо поліпшення системи.

## Встановлення та запуск

Потрібен Python 3.9 або новіший.

```bash
git clone <адреса репозиторію>
cd coursework-b19
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
jupyter notebook notebooks/coursework_B19.ipynb
```

Клітинки потрібно виконувати по порядку. Для швидкої перевірки достатньо розділів 1–3. Повне виконання може тривати довго, бо основна серія складається з багатьох прогонів по 100 000 год модельного часу.

## Результати

Таблиці (CSV, роздільник `;`, кодування UTF-8 з BOM для коректного відкриття в Excel) і рисунки (PNG) зберігаються в каталог `results/` поруч із ноутбуком. Інший каталог можна задати змінною середовища `B19_OUT`:
